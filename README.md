# JWH

เว็บไซต์รายงานที่ต้องใส่รหัสผ่านก่อนเปิด ข้อมูลรายงานถูกบีบอัดและเข้ารหัสด้วย AES-256-GCM โดยใช้ PBKDF2-SHA-256 จำนวน 600,000 รอบและ salt แบบสุ่ม ไม่เก็บรหัสผ่านไว้ใน repository

เปิด index.html ด้วย Edge หรือ Chrome หรือเปิด GitHub Pages เมื่อได้รับรหัสจากผู้จัดทำ ระบบไม่จดจำรหัสและกลับสู่หน้าล็อกเมื่อโหลดใหม่ ผู้มีรหัสสามารถดูและดาวน์โหลดรายงานได้

ไฟล์เข้ารหัสสามารถดาวน์โหลดไปทดสอบรหัสแบบออฟไลน์ได้ ความปลอดภัยจึงขึ้นกับความยาวและความคาดเดายากของรหัส ระบบนี้ไม่มีบัญชีผู้ใช้หรือการเพิกถอนสิทธิ์รายบุคคล
